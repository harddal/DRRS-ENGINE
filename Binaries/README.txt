================================================================================
DRRS Engine
================================================================================

A custom 3D game engine for Windows: integrated level editor, per-pixel PBR
shading, baked lightmaps, NVIDIA PhysX, AngelScript scripting, Recast/Detour
navigation, and a data-driven particle system.


RUNNING
--------------------------------------------------------------------------------
Run Engine.exe from this folder so that relative content paths under content/
resolve correctly.

In-game keys:
  F1     Toggle editor mode
  F2     Toggle debug console
  WASD   Move
  Mouse  Look
  LMB    Primary fire
  RMB    Alternate fire / aim
